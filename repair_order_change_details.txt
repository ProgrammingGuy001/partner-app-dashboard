Repair Order Change Details
Generated: 2026-07-06

1. Purpose

The site requisite flow now creates a real Odoo repair order with Parts tab line items.
Previously, the requested parts were only written into the repair order internal notes.
That made the repair order visible in Odoo, but its Parts table stayed empty.

2. Backend repair order creation

File:
app/services/odoo_service.py

Main function:
OdooService.create_repair_order_for_requisite

What it does:
It creates an Odoo repair.order for a submitted site requisite.
It links the repair order to the sale order.
It sets partner, schedule date, locations, internal notes, and now Parts line items.

3. Parts line creation

File:
app/services/odoo_service.py

Main function:
OdooService._repair_order_part_moves

What it does for each requested item:
It reads the submitted product_name.
It finds the matching Odoo product.product with name_search.
It reads the product UoM from Odoo.
It builds a stock.move command for repair.order.move_ids.

Fields sent to Odoo for each Parts line:
name: submitted product name
product_id: resolved Odoo product id
product_uom_qty: requested quantity
product_uom: resolved Odoo unit of measure
repair_line_type: add
location_id: repair source location
location_dest_id: repair destination location
company_id: company id
picking_type_id: repair operation type, when available
date: scheduled date, when available
description_picking: issue description, when available
x_studio_description: issue description, when available

Important behavior:
If a product cannot be found in Odoo, submission fails instead of creating an empty repair order.
If required repair locations are missing, submission fails instead of creating an unusable order.

4. Internal notes

File:
app/services/odoo_service.py

Main function:
OdooService._repair_order_notes

What it does:
It still writes a readable HTML summary into the repair order notes.
This includes sales order, cabinet position, SR POC, expected delivery, DO number, and item details.
User-entered text is escaped before being inserted into the HTML note.
